# C1 Finite-to-Classical Dictionary

Status: proof-focus document. This file exists to support the highest-priority conjecture only.

## Highest-priority conjecture C1

```text
Finite rational-ray nest stabilization
  iff Mandelbrot fiber triviality
  iff MLC
```

The finite core must not claim generic singleton resolution. It may only define finite separation data and the finite nests generated by that data. The classical bridge is discharged by theorem tags tied to Schleicher-style fiber theory and rational-ray landing.

## Dictionary

| Finite-regime object | Classical referent | Internal status |
|---|---|---|
| `RayAddrFinite` | rational external ray address | finite symbolic data |
| `LandingTag` | theorem-backed ray landing assertion | theorem tag |
| `LandedRay` | rational ray with landing theorem attached | finite data + theorem tag |
| `SeparationLine` | separation line made from landed rational rays | finite combinatorial separator |
| `SeparationCatalogue(k)` | first `k` certified separation lines | finite catalogue |
| `SameFiberLevel(k)` | not separated by any catalogue entry through level `k` | finite non-separation predicate |
| `FiberNest` | decreasing family of finite non-separation predicates | finite stream |
| `Stabilizes` | singleton fiber/triviality claim | meta-level only |
| `MLC` | local connectivity of the Mandelbrot set | external conjectural/topological statement |

## Allowed finite claims

The finite core may prove:

1. a ray address is rational and encoded canonically;
2. a landing theorem tag is attached to a rational address;
3. a separation line is built from landed rational rays;
4. two finite incidence packages are separated by a catalogue entry;
5. two finite incidence packages are not separated through finite depth `k`;
6. a finite nest refines another finite nest by catalogue inclusion.

## Forbidden finite claims

The finite core must not assert:

1. a generic boundary object is a singleton;
2. all generic nests stabilize;
3. MLC is true;
4. finite-depth non-separation equals classical equality;
5. a root handle alone is a point;
6. a coordinate record is an analytic complex number.

## The bridge theorem shape

The proof target is not to solve MLC. It is to prove the equivalence of formulations:

```text
C1-A. The finite catalogue relation is extensionally the same as fiber separation.
C1-B. A finite nest stabilizes exactly when the corresponding fiber is trivial.
C1-C. Triviality of all fibers is equivalent to MLC by the cited fiber theorem.
```

`C1-A` is the project-owned grammar adequacy theorem. `C1-B` is mostly unpacking definitions once C1-A is correct. `C1-C` is a theorem-tag bridge to the literature.

## Immediate proof obligation

The next proof move is to define `separates_by_catalogue(a,b,k)` and show:

```text
not SameFiberLevel(a,b,k)
  iff some certified separation line in catalogue prefix k separates a and b.
```

Then define:

```text
SameFiberStream(a,b) := forall k, SameFiberLevel(a,b,k)
```

and bridge that stream to the classical fiber relation by theorem tag.
