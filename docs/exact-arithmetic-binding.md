# Exact-arithmetic binding table

This repository's binding table for
`docs/rational-interval-arithmetic-spec.md`, section 6. One row per module
that instantiates a layer, with its conformance class and the criteria it
currently fails. The specification is the canonical copy from
`larsbx/finite-math-kernels`; the rows below are this repository's and are
enforced by `tools/audit_exact_arithmetic.py`.

The table moved here from section 6.2 of the specification, unchanged. The
canonical specification asks each consumer to keep its own binding table, and
keeping this one inside a document shared with two other repositories meant a
row about this repository could only be edited by editing their copy too.
