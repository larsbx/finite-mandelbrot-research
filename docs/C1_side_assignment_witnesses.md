# C1 Side-Assignment Witnesses

Status: C1 proof scaffold.

This document defines the finite witness that lets the C1 separation predicate say that two finite incidence objects lie on different sides of an admissible rational-ray separator.

This is not a geometric point-in-region test. In the finite regime there are no analytic points. A side assignment is a certified relation among finite objects:

- an incidence object reference;
- an admissible separator code;
- a finite side label;
- a witness payload made from rational ray-address order, wake membership, or theorem-tagged component-boundary data.

## 1. Objects

Let `A` be an incidence object reference, usually a `PointVertex` carrier such as:

```text
PointVertex({RootHandle, RayAddressSet, DyadicBox})
```

Let `S` be an admissible separator code from `C1_admissible_separator_codes.md`.

A side-assignment witness has the form:

```text
SideAssignmentWitness(
  object_ref=A,
  separator=S,
  side=Left | Right | OnSeparator,
  evidence=RayOrder | WakeMembership | ComponentBoundaryTag
)
```

Only `Left` and `Right` may be used to prove separation. `OnSeparator` is a structural equality case, not a separation case.

## 2. Evidence kinds

### 2.1 Ray-order evidence

For two-ray separators, the evidence is a finite cyclic-order statement in `Q/Z`.

```text
RayOrder(
  object_ray_addr,
  boundary_addr_0,
  boundary_addr_1,
  cyclic_interval_id
)
```

The verifier checks normalized rational addresses and cyclic interval membership by integer comparison only.

### 2.2 Wake-membership evidence

For Misiurewicz/parabolic wakes, the evidence is a finite symbolic wake membership certificate:

```text
WakeMembership(
  object_symbolic_address,
  wake_boundary_addr_0,
  wake_boundary_addr_1,
  kneading_prefix,
  prefix_length
)
```

This is a finite address/kneading check. It does not evaluate analytic rays.

### 2.3 Component-boundary evidence

For separators using hyperbolic-component boundary arcs, the side assignment may depend on a theorem-tagged component-boundary separation statement.

```text
ComponentBoundaryTag(
  component_id,
  boundary_anchor_codes,
  theorem_tag=HyperbolicBoundaryLanding
)
```

This is admissible only when the separator code itself is admissible and the theorem tag is one of the allowed established tags.

## 3. Separation rule

A finite separator proves `Separated_k(A,B)` only if:

1. the separator code is admissible;
2. `A` has a valid side-assignment witness for the separator;
3. `B` has a valid side-assignment witness for the same separator;
4. both witnesses use the same separator code id;
5. the side labels are `Left` and `Right` in either order;
6. neither side assignment is `OnSeparator`.

Formally:

```text
Separated_k(A,B,S)
  := Admissible(S)
     ∧ Side(A,S)=Left
     ∧ Side(B,S)=Right
```

or the same with `Left` and `Right` swapped.

## 4. Non-separation boundary

Failure to find opposite side assignments in a finite prefix means only:

```text
SameFiberPrefix_k(A,B)
```

It does not mean:

```text
SameFiber(A,B)
```

and it does not imply generic stabilization.

## 5. Next proof obligation

The next C1 obligation is:

```text
SideAssignmentSoundness:
  every accepted finite side-assignment witness corresponds to the matching
  classical side of the Schleicher-style separation line.
```

The converse, side-assignment completeness for all classical separations generated by admissible rational-ray separators, is part of catalogue extensionality.
